# wotcost

Номинальная оценка имущества аккаунта World of Tanks. Приложение показывает, сколько техника в ангаре и прочее имущество стоят в валюте реалма: евро для EU, доллар для NA, юань для ASIA.

Это не сумма, которую можно вывести живыми деньгами, и не рыночная цена аккаунта. Приложение неофициальное и не связано с Wargaming.

## Установка

Нужен Android 8 или новее.

Скачайте [wotcost-debug.apk](https://github.com/bndby/mt-cost/releases/download/debug/wotcost-debug.apk) и откройте файл на телефоне. Если система спросит, разрешите установку из браузера или из файлового менеджера.

Каждый пуш в `master` заменяет этот файл новой сборкой. Подпись тестовых сборок одна и та же, поэтому обновление ставится поверх предыдущего APK с этой страницы. Поверх копии из Play оно не встанет: у магазина другой ключ. Страница релиза: [тестовая сборка](https://github.com/bndby/mt-cost/releases/tag/debug).

## Что на экране

1. Выбор реалма: NA, EU или ASIA. Нажатие сразу открывает вход Wargaming.
2. После входа — оценка. В заголовке код реалма и ник, при наличии клана ещё и тег. Крупная сумма в валюте реалма, ниже строки имущества: название, количество и сумма.
3. Настройки: тема и язык. Выход из аккаунта — кнопка в верхней панели. Он сразу отзывает токен у WG.

Пароль в приложение не вводится. Учётные данные остаются на странице WG OpenID. Своего сервера нет: токен сессии живёт на устройстве, пока приложение открыто. Одна сессия — один аккаунт одного реалма.

## Как считается оценка

Имущество переводится в серебро, сумма серебра — в золото, золото — в валюту реалма входа. На экране общая сумма и каждая строка показаны в этой валюте, с двумя знаками после запятой.

В оценку входит то, у чего известны и владение, и цена:

- танки в ангаре по каталожной цене энциклопедии, без модулей;
- серебро, золото и боны на счету;
- свободный опыт;
- личные резервы;
- оставшиеся дни танкового премиум-аккаунта, разложенные по пакетам золота магазина WG.

Нет цены в API — этой единицы в оценке нет. Модули, оборудование, снаряжение, стили и расходники на экран не выводятся.

Курсы — снимки, не живая витрина. Их правят вручную в `.env.example`.

| Курс | Снимок |
| --- | --- |
| Серебро | 1 золото = 400 серебра. Оценка использует обратную сторону официального обмена |
| Боны | 1 бона = 1,6 золота. Это договорённость оценки, не официальный обмен |
| Свободный опыт | 1 золото = 25 опыта |
| Золото EU | 30 500 золота за 99,99 € |
| Золото NA | 25 000 золота за 99,99 $ |
| Золото ASIA | 25 000 золота за 625 ¥ |

Курс золота — крупнейший пакет только из золота в премиум-магазине реалма, без скидки и без комплекта. Снимок от 1 октября 2026.

## Язык и тема

Язык по умолчанию — язык телефона, если он есть среди языков клиента World of Tanks. Иначе русский. В настройках можно выбрать один из двадцати языков клиента или снова «Язык устройства». На Android 13 и новее тот же выбор виден в системной настройке языка приложения.

Тема: светлая, тёмная или как на устройстве. Пока игрок не выбрал, приложение повторяет переключатель тёмной темы системы. На Android 12 и новее цвета берутся с обоев. Значки валют остаются своих цветов: боны бронзовые, золото жёлтое, серебро серое.

## Сборка

Нужны JDK 17 и Android SDK. Каталог SDK должен быть в `ANDROID_HOME`.

```bash
cp .env.example .env
```

В `.env` укажите `WG_APPLICATION_ID` из [Wargaming Developer Room](https://developers.wargaming.net/). Файл в git не входит. Снимки курсов уже лежат в `.env.example`.

Отладочный APK:

```bash
cd android
./gradlew :app:assembleDebug
```

Файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

Подписанный App Bundle для Play, локально:

```bash
scripts/build-android-aab.sh
```

Скрипту нужны `credentials.json` и ключ загрузки Play. Их в git нет. Готовый файл — `wotcost-<version>.aab` в корне репозитория. Отпечаток сертификата загрузки: `EE:13:1B:7D:1F:B4:1F:88:4A:C9:38:D9:A9:D4:5D:CA:40:FC:A4:BF`.

Юнит-тесты:

```bash
cd android
./gradlew :app:testDebugUnitTest
```

## GitHub Actions

Пуш в любую ветку запускает юнит-тесты и кладёт debug APK в артефакты прогона.

Пуш в `master` дополнительно:

- публикует этот APK в релиз с тегом `debug`;
- собирает подписанный AAB и кладёт его в артефакты прогона.

AAB на закрытое тестирование Play пока не отправляется. `versionCode` такого AAB — номер прогона Actions. `versionName` берётся из Gradle и сейчас равен `1.0.0`.

## Конфиденциальность

Политика: <https://bndby.github.io/mt-cost/privacy/>.

Приложение передаёт Wargaming идентификатор аккаунта и токен сессии, чтобы прочитать имущество. Само оно эти данные не собирает и никуда больше не отправляет.

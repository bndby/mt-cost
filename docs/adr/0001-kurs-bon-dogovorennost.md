# Курс бон — договорённость этой Оценки

Официального обмена бон на серебро, золото или валюту Реалма нет. Оценка всё равно считает боны Имуществом: снимок 1 бон = 1,6 золота. Дальше это золото идёт в валюту Реалма по Курсу золота. Пересмотр вручную.

## Considered Options

- Исключить боны из Оценки — отвергнуто: баланс есть, а герой его не считает.
- Количество без стоимости — отвергнуто: ломает формат столбика.
- Подставить серый рынок — отвергнуто заранее.
- Назвать 1,6 официальным курсом — отвергнуто: публичного обмена нет.
- Снимок 1 бон = 1 золото — отвергнуто: эталон этой Оценки — 1,6 золота.
- Снимок 1 бон = 2 золота — отвергнуто: эталон этой Оценки — 1,6 золота.

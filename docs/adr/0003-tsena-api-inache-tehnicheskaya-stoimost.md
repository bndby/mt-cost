# Цена имущества: API, иначе техническая стоимость

Если Public API отдаёт официальную цену единицы в серебре или золоте — Оценка берёт её. Если цены в API нет, а владение есть — для Мира танков подставляется техническая стоимость ADR-0002. Прайс ADR-0002 на WG-аккаунт не переносится: для WG нужны свои курсы из открытых источников.

Так уже считаются ТПА (срок в API, пакеты из ADR-0002) и боны (баланс в API, курс из ADR-0001). Обратное — всегда техническая стоимость даже при каталоге — отвергнуто: у премов Lesta с заполненным `price_gold` каталог совпадает с таблицей уровней, и это официальная цена танка.

## Considered Options

- Только официальная цена API — отвергнуто: владение без каталога (свободный опыт, награды с пустым `price_gold`, ТПА) выпадает из Оценки.
- Всегда техническая стоимость ADR-0002, даже если каталог заполнен — отвергнуто: каталог — официальная цена; для танков с `price_gold` это те же числа, что таблица уровней.
- Перенести ADR-0002 на WG-аккаунт — отвергнуто: другая экономика; витрина WG (`price_gold`) уже не совпадает с таблицей Lesta.

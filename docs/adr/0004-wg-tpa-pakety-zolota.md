# WG-ТПА считается пакетами золота внутриигрового магазина WG

ТПА WG-аккаунта не берёт ADR-0002. Public API даёт только `premium_expires_at`. Оценка раскладывает оставшиеся сутки жадно по официальным пакетам золота WG: 360 / 180 / 90 / 30 / 14 / 7 / 3 / 1 день = 20 500 / 11 900 / 6 900 / 2 500 / 1 800 / 1 250 / 650 / 250. Длинные пакеты — живая [новость о снижении цены](https://worldoftanks.com/en/news/general-news/premium-account-price-drop/); полный ряд — [снимок гайда Going Premium на Wayback, 2026-01-23](http://web.archive.org/web/20260123165347/https://worldoftanks.com/en/content/guide/wot_economy/going_premium/) (живой URL с 2026-09-09 отдаёт 404). Сутки вверх — как у Мира танков.

Отвергнуто: перенести ADR-0002; считать от USD Премиум-магазина; пакеты Modern Armor (другие числа).

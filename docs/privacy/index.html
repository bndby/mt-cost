Политика конфиденциальности

Приложение WoT Cost. Дата: 1 октября 2026.

Что это

WoT Cost показывает номинальную оценку имущества WG-аккаунта (World of Tanks по WG Public API) в валюте Реалма входа: евро на EU, доллар на NA, юань на ASIA. Это неофициальное приложение, не связанное с Wargaming. Оценка — не сумма к выводу живыми деньгами.

Вход

Пароль и email аккаунта приложение не собирает и не принимает. Вход только через WG OpenID: учётные данные вводятся на странице WG. Перед этим игрок выбирает Реалм (NA, EU или ASIA). После успеха WG возвращает в приложение access_token, срок действия, идентификатор аккаунта и ник.

Возврат идёт через статическую страницу https://bndby.github.io/mt-cost/auth/callback, которая сразу открывает приложение по адресу mtcost://auth/callback с тем же query. Страница ничего не сохраняет: нет cookie, localStorage и запросов на сторонние серверы.

Что хранится на устройстве

Токен сессии живёт только в памяти приложения, пока оно запущено. Своего сервера у WoT Cost нет: мы не принимаем, не копируем и не храним токен, ник или оценку на своих машинах.

Запросы к WG

Пока сессия жива, приложение по HTTPS вызывает API выбранного Реалма (api.worldoftanks.com, api.worldoftanks.eu, api.worldoftanks.asia) с application_id и access_token: выход, продление токена, снимок аккаунта (ангар, серебро, золото) и цены техники из энциклопедии. Эти данные обрабатывает Wargaming по своим правилам.

application_id — публичный идентификатор автономного приложения из Wargaming Developer Room; он встроен в клиент.

Выход и удаление

Кнопка «Выйти» вызывает выход у WG и забывает локальный токен. После этого приложение больше не запрашивает имущество. Отдельного аккаунта WoT Cost нет — удалять на нашей стороне нечего.

Аналитика, реклама, дети

Нет рекламы, трекеров, продажи данных и функций для детей. Приложение рассчитано на игроков World of Tanks 16 лет и старше.

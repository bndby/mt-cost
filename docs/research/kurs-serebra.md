# Курс серебра в Мире танков (Lesta)

Исследование 2026-08-30. Источники: официальный портал tanki.su, Центр поддержки Lesta, Lesta Wiki, справочник Public API (`developers.lesta.ru`). Форумы и сторонние калькуляторы не используются как источник истины.

## Ответ

**1 золото = 400 серебра.** Это постоянный официальный внутриигровой обмен Золота на Серебро. Обратного постоянного обмена (серебро → золото) нет: для Оценки берётся только обратная сторона того же курса (400 серебра = 1 золото). Публичный API это число не отдаёт — его нужно фиксировать из витрины обмена / гайда портала.

## Сколько серебра даёт 1 золото

Курс обмена: **1 → 400**.

Зафиксирован в двух независимых официальных текстах Lesta:

1. Гайд портала «Перевод валюты и ресурсов»: экономика позволяет перевести «Золото в серебро», «Курс обмена: 1 → 400». Обмен выполняется в клиенте: в правом верхнем углу экрана — «Обменять», в окне указывается количество золота или серебра.
   - https://tanki.su/ru/content/guide/economy/conversion/
2. Статья Центра поддержки «Что продаётся и как покупать в Премиум магазине?» (опубликована 5 сентября 2017, обновлена ~июнь 2026): за золото можно «приобрести серебро (1 единица золота = 400 серебра)».
   - https://lesta.ru/support/ru/products/mt/article/10540/

То же число на Lesta Wiki (статья «Игровое золото»): «За 1 золото можно купить 400 серебра».
- https://wiki.lesta.ru/ru/Мир_танков:Игровое_золото

Источник истины для Оценки: гайд портала (п. 1). Статья поддержки подтверждает то же равенство в описании Золота. Клиентский диалог «Обменять» — операционная витрина того же курса.

## Можно ли официально обменять серебро на золото

Постоянного обмена серебра на золото нет.

Гайд «Перевод валюты и ресурсов» перечисляет ровно два постоянных перевода: золото → серебро и боевой опыт элитной техники → свободный опыт (за золото). Обратного направления «серебро → золото» в этом гайде нет.

Серебро → золото появляется только как **временное событие** «Золотой вагон» ко Дню рождения игры. Это не постоянный курс и не обращение 1→400:

- Нужны особые «золотые билеты» события, без них обмен недоступен.
- Курс зависит от наполнения общего хранилища и хуже постоянного 400 серебра за 1 золото.

Официальные страницы события:

- 2026 (обновление 1.44): вагон позволяет обменивать серебро на золото, используя золотые билеты; «чем больше золота в вагоне, тем лучше курс»; ежедневное пополнение до 125 000 000 золота. Окно: 6 августа 20:00 МСК — 20 августа 3:00 МСК.
  - https://tanki.su/ru/content/archive_release_notes/1_44_release/
  - https://tanki.su/ru/den-rozhdeniya-2026/
- 2025, явные ступени (серебро → 300 золота): более 100 000 000 золота в вагоне — 240 000 серебра = 300 золота; 25 000 000–100 000 000 — 360 000 = 300; менее 25 000 000 — 750 000 = 300. Это 800 / 1 200 / 2 500 серебра за 1 золото, не 400.
  - https://tanki.su/ru/den-rozhdeniya-2025/
  - https://tanki.su/ru/content/rules/den-rozhdeniya-2025-reglament/

Для Оценки событие «Золотой вагон» не подменяет Курс серебра: это разовый, лимитированный и худший обмен. Цепочка Оценки (сумма серебра → золото) использует обратную сторону постоянного курса 1 золото = 400 серебра.

## Отдаёт ли публичный API это число

Нет. Число нужно фиксировать из гайда / витрины обмена.

Справочник методов Мира танков на `developers.lesta.ru` не содержит метода магазина, обмена валют или поля «курс золото/серебро». Проверенные методы, которые касаются валют:

- `wot/encyclopedia/info/` — константы Танкопедии: `game_version`, языки, нации, типы техники, `tanks_updated_at`. Курса нет.
  - https://developers.lesta.ru/reference/all/wot/encyclopedia/info/
- `wot/encyclopedia/vehicles/` — цены техники раздельно: `price_credit` (серебро) и `price_gold` (золото). Это цены лотов, не коэффициент обмена.
  - https://developers.lesta.ru/reference/all/wot/encyclopedia/vehicles/
- `wot/account/info/` — при `access_token` отдаёт балансы `private.credits` (серебро) и `private.gold` (золото), не курс.
  - https://developers.lesta.ru/reference/all/wot/account/info/

Полный список методов Мира танков (аккаунты, аутентификация, укрепрайоны, глобальная карта, танкопедия, рейтинги, кланы) — без обмена валют:
- https://developers.lesta.ru/reference/

Базовый URL кластера Lesta: `https://api.tanki.su/` (ключ `demo` на 2026-08-30 отвечает `DEMO_APPLICATION_IS_BLOCKED`; для живых запросов нужен свой `application_id` с https://developers.lesta.ru/).

## Меняется ли курс и как это увидеть

Постоянный Курс серебра в официальных текстах подаётся как фиксированное равенство, без оговорки «может меняться». На той же странице гайда курс перевода опыта **явно** может меняться «в зависимости от игровых событий и акций» — для золота→серебра такой оговорки нет.

Статья поддержки с формулировкой «1 единица золота = 400 серебра» существует с 2017 года и сохраняет то же число после обновления ~июнь 2026.

Как увидеть смену, если Lesta её когда-нибудь объявит:

1. Текст «Курс обмена: 1 → 400» на https://tanki.su/ru/content/guide/economy/conversion/
2. Формулировка в https://lesta.ru/support/ru/products/mt/article/10540/
3. Диалог «Обменять» в клиенте (правый верхний угол игрового экрана)

Программно курс не подтянуть: API его не отдаёт. Для Оценки число 400 фиксируется в приложении; пересмотр — ручная сверка этих трёх мест.

Событийный курс «Золотого вагона» меняется внутри события и не является Курсом серебра.

## Для Оценки

| Вопрос | Решение |
| --- | --- |
| Курс серебра | 1 золото = 400 серебра |
| Серебро → золото в Оценке | Обратная сторона того же курса: золото = серебро / 400 |
| Постоянный обмен серебра на золото | Нет |
| «Золотой вагон» | Не использовать как Курс серебра |
| API | Балансы и цены лотов есть; коэффициента обмена нет |
| Как обновлять | Сверять гайд портала, статью поддержки и клиентский «Обменять» |
